# SQL — Prática e Desenvolvimento

Repositório dedicado à prática e ao aprofundamento em **SQL**, por meio de exercícios, desafios e análises utilizando diferentes bancos de dados.

O projeto tem como foco desenvolver **raciocínio lógico, domínio de consultas, manipulação de dados e capacidade de solucionar problemas utilizando SQL**.

---

## Sobre o Projeto

Este repositório reúne exercícios desenvolvidos ao longo dos estudos de SQL, organizados de forma progressiva e estruturada.

A proposta é trabalhar com **diferentes bases de dados**, permitindo praticar os conceitos de SQL em diferentes contextos e conhecer particularidades de cada ambiente.

Os exercícios são organizados por **bases de dados → tema → exercício**, facilitando a navegação, revisão e evolução do projeto.

---

## Objetivos

* Consolidar os fundamentos de SQL
* Desenvolver raciocínio lógico para resolução de problemas
* Praticar consultas e manipulação de dados
* Aprofundar conhecimentos em relacionamentos entre tabelas
* Praticar conceitos intermediários e avançados de SQL
* Registrar e documentar a evolução dos estudos
* Criar uma base de consultas para futuras revisões

## Metodologia de Estudo

Os exercícios são desenvolvidos buscando mais do que apenas chegar ao resultado esperado.

Para cada problema, o foco está em:

1. Entender o problema proposto
2. Identificar as tabelas e informações necessárias
3. Definir a lógica da consulta
4. Desenvolver a solução em SQL
5. Validar o resultado
6. Analisar possíveis alternativas para a solução
7. Registrar o exercício no repositório

O objetivo é desenvolver a capacidade de **pensar em SQL**, e não apenas memorizar comandos.

## Evolução

Este é um projeto **contínuo**, desenvolvido paralelamente aos estudos de análise de dados.
